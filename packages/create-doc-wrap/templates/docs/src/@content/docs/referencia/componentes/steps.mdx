## Quando usar

Use `Steps` quando a ordem das ações fizer parte da compreensão do conteúdo. É um bom formato para cadastro, configuração, revisão, publicação e qualquer fluxo em que pular etapas possa gerar erro.

## Import

```mdx
import { Steps } from "@presentation/components/docs/Step.tsx";
```

## API disponível hoje

`Steps` recebe uma prop `steps`, que é uma lista de itens com `title`, `children` e `number` opcional. Quando o número não é informado, o componente numera automaticamente os passos em sequência.

## Exemplo

```mdx
export const passos = [
  {
    title: "Abra a tela",
    children: "Acesse o menu principal e selecione a rotina desejada."
  },
  {
    title: "Preencha os dados",
    children: "Revise as informações obrigatórias antes de salvar."
  }
];

<Steps steps={passos} />
```
