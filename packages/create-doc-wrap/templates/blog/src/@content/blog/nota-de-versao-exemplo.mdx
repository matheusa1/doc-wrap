## Resumo da versão

Use uma nota de versão para explicar o que mudou no sistema e por que a mudança é relevante para os usuários. Comece pelo impacto prático antes de listar detalhes técnicos.

## O que mudou

- Nova tela de acompanhamento de solicitações.
- Ajustes de usabilidade no fluxo de cadastro.
- Correções em mensagens de validação.
- Melhorias de desempenho em consultas frequentes.

## Orientação para usuários

Informe se a mudança exige alguma ação, como revisar permissões, atualizar dados ou comunicar equipes internas.

## Onde documentar detalhes

Quando a funcionalidade precisar de instruções completas, crie ou atualize uma página em `src/@content/docs` e adicione o link no post.
