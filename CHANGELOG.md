# Changelog

Este arquivo passa a ser gerenciado pelo `release-please`.

O fluxo inicial de release considera a trilha CLI em `develop-cli` e começará a registrar versões do pacote raiz `doc-wrap` a partir do bootstrap configurado no repositório.

Enquanto o projeto ainda não tiver `schemaVersion` nem `doc-wrap migrate`, mudanças estruturais relevantes no template ou na configuração devem aparecer aqui com instruções de atualização manual para projetos já gerados.
