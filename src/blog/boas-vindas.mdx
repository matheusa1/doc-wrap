## Área de publicações

Este espaço demonstra como o template organiza publicações em formato de blog. Use-o para notas de versão, comunicados operacionais, avisos de manutenção, treinamentos e mudanças relevantes para os usuários do sistema.

## O que esperar

- Posts escritos em MDX dentro de `src/blog`.
- Categorias usadas como filtros na listagem.
- Ordenação automática por `publishedAt`.
- Campo opcional `eventAt` para eventos futuros.

Substitua estes exemplos pelos comunicados reais do seu sistema antes de publicar o template para usuários finais.
