## Bem-vindo

Esta central organiza os guias do usuário em páginas leves escritas com MDX. Cada arquivo dentro de `src/docs` vira uma rota automaticamente em `/docs`.

<Callout title="Como esta página funciona" type="info">
  A navegação lateral é temporária e usa `import.meta.glob` para listar os documentos cadastrados no projeto.
</Callout>
