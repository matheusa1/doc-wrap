## Bem-vindo

Esta central organiza os guias do usuário em páginas leves escritas com MDX. Cada arquivo dentro de `src/docs` vira uma rota automaticamente em `/docs`.

<Callout title="Como esta página funciona" type="info">
  A navegação lateral é temporária e usa `import.meta.glob` para listar os documentos cadastrados no projeto.
</Callout>

## Navegação inicial

<Step number={1} title="Use a sidebar">
  Selecione um guia na lateral para abrir o documento correspondente.
</Step>

<Step number={2} title="Busque por titulo ou descrição">
  Digite uma palavra no campo de busca para filtrar os documentos localmente.
</Step>

<Step number={3} title="Crie novos arquivos MDX">
  Adicione novos arquivos em `src/docs` para expandir a central sem alterar manualmente a lista de rotas.
</Step>
