## Quando usar

Use o cadastro de parceiros para registrar clientes, fornecedores, produtores, transportadoras e outros contatos comerciais usados na operação rural.

<Callout title="Antes de começar" type="hint">
  Separe os dados básicos do parceiro, como nome, documento, telefone, endereço e tipo de relacionamento comercial.
</Callout>

## Boas praticas

- Evite duplicar parceiros com nomes parecidos.
- Use uma classificação clara para facilitar filtros.
- Mantenha os contatos atualizados para reduzir retrabalho.
