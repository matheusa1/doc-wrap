## Visão geral

As contas financeiras representam os locais onde o dinheiro entra ou sai, como caixa, banco, cooperativa ou carteira digital.

<Callout title="Atenção" type="warning">
  Cadastre contas separadas para operações diferentes quando precisar acompanhar saldos e relatórios com mais precisão.
</Callout>

## Organização sugerida

- Uma conta para caixa físico.
- Uma conta para cada banco usado na fazenda.
- Uma conta separada para operações de safra, quando necessário.
