## Visao geral

As contas financeiras representam os locais onde o dinheiro entra ou sai, como caixa, banco, cooperativa ou carteira digital.

<Callout title="Atencao" type="warning">
  Cadastre contas separadas para operacoes diferentes quando precisar acompanhar saldos e relatorios com mais precisao.
</Callout>

## Cadastro da conta

<Step number={1} title="Defina o tipo de conta">
  Escolha se a conta representa caixa, banco, cooperativa ou outro controle financeiro.
</Step>

<Step number={2} title="Informe os dados de identificacao">
  Preencha nome, descricao e dados complementares que ajudem a reconhecer a conta no dia a dia.
</Step>

<Step number={3} title="Acompanhe as movimentacoes">
  Use a conta em lancamentos de receitas, despesas e transferencias para manter o saldo atualizado.
</Step>

## Organizacao sugerida

- Uma conta para caixa fisico.
- Uma conta para cada banco usado na fazenda.
- Uma conta separada para operacoes de safra, quando necessario.
