## Estrutura de arquivo

Cada documento deve ser criado em `src/docs`. O caminho do arquivo define a rota pública.

```text
src/docs/primeiros-passos/acesso-inicial.mdx
src/docs/primeiros-passos/index.mdx
```

Esses arquivos serão acessados em:

```text
/docs/primeiros-passos/acesso-inicial
/docs/primeiros-passos
```

<Callout title="Rotas automáticas" type="info">
  Não é necessário registrar o documento em um arquivo de rotas. O mapa em `src/docs-map.ts` usa `import.meta.glob` para carregar todos os arquivos MDX da pasta.
</Callout>

## Frontmatter obrigatório

Use este bloco no início do arquivo:

```mdx
---
title: Acesso inicial
description: Como acessar o sistema pela primeira vez.
category: Primeiros passos
order: 1
author: Equipe do Produto
updatedAt: 2026-04-27
---
```

Campos disponíveis:

- `title`: nome exibido na página, sidebar e resultados de busca.
- `description`: resumo curto do conteúdo.
- `category`: contexto exibido no cabeçalho e útil para classificação editorial.
- `order`: posição do documento dentro do mesmo diretório ou seção.
- `author`: responsável pelo conteúdo.
- `updatedAt`: data de revisão no formato `YYYY-MM-DD`.

## Conteúdo em MDX

Depois do frontmatter, escreva normalmente com Markdown:

```mdx
## Objetivo

Explique quando o usuário deve usar esta funcionalidade.

## Passo a passo

1. Acesse o menu principal.
2. Abra a tela desejada.
3. Revise as informações antes de salvar.
```

Você também pode importar componentes:

```mdx
import { Callout } from "@/components/docs/Callout.tsx";

<Callout title="Antes de começar" type="hint">
  Separe as informações necessárias antes de iniciar o cadastro.
</Callout>
```

## Boas práticas

- Escreva títulos objetivos e orientados à tarefa.
- Prefira uma página por rotina ou decisão importante.
- Use `h2` para seções principais e `h3` para detalhes.
- Mantenha a descrição curta, porque ela aparece na busca e no cabeçalho da página.
- Atualize `updatedAt` sempre que revisar regras, telas ou procedimentos.
