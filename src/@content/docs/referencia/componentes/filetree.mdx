## Quando usar

Use `FileTree` para explicar organização de projeto, limites entre módulos ou a posição de arquivos importantes dentro do template. Ele é especialmente útil em documentação técnica, onboarding e guias de manutenção.

## Import

```mdx
import { FileTree } from "@presentation/components/docs/FileTree.tsx";
```

## API disponível hoje

O componente é composto por `FileTree`, `FileTree.Folder` e `FileTree.File`. Pastas e arquivos aceitam `name`, `description` e `active`, e a pasta também aceita `defaultOpen`, embora a renderização atual seja estática e trate esse campo mais como semântica do exemplo do que como interação real.

## Exemplo

```mdx
<FileTree>
  <FileTree.Folder name="src" defaultOpen>
    <FileTree.Folder name="@content">
      <FileTree.Folder name="docs">
        <FileTree.File name="introducao.mdx" active />
      </FileTree.Folder>
    </FileTree.Folder>
  </FileTree.Folder>
</FileTree>
```
