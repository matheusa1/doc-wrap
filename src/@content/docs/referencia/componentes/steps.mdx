## Quando usar

Use `Steps` para representar um procedimento sequencial, como cadastro, configuração, revisão ou publicação.

## Uso

```mdx
import { Steps } from "@presentation/components/docs/Step.tsx";

export const passos = [
  {
    title: "Abra a tela",
    children: "Acesse o menu principal e selecione a rotina desejada."
  },
  {
    title: "Preencha os dados",
    children: "Informe os campos obrigatórios antes de salvar."
  }
]

<Steps steps={passos} />
```
