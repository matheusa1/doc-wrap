## Quando usar

Use `Cards` para sugerir próximas leituras, agrupar atalhos por assunto ou organizar páginas-hub. Ele funciona melhor quando o documento precisa apontar caminhos e não apenas explicar um único fluxo linear.

## Import

```mdx
import { Cards } from "@presentation/components/docs/Cards.tsx";
```

## API disponível hoje

`Cards` recebe a quantidade de colunas em `num`. Cada `Cards.Card` aceita `title`, `description`, `href`, `icon`, `arrow` e conteúdo opcional. Links internos usam `react-router-dom`, enquanto URLs externas são abertas como `<a>`.

## Exemplo

```mdx
import { Blocks, Network } from "lucide-react";

<Cards num={2}>
  <Cards.Card
    icon={<Blocks />}
    title="Módulos"
    description="Conheça os domínios e limites de responsabilidade do sistema."
    href="/docs/arquitetura/modulos"
    arrow
  />
  <Cards.Card
    icon={<Network />}
    title="Integrações"
    description="Veja contratos, eventos e dependências externas."
    href="/docs/arquitetura/integracoes"
    arrow
  />
</Cards>
```
